## Local database setup

Requires PostgreSQL 16+ reachable via `DATABASE_URL`.

```bash
createdb ngc_erp
export DATABASE_URL=postgres://postgres:postgres@localhost:5432/ngc_erp
bash scripts/db-migrate.sh          # applies every migration in supabase/migrations, in order
bash scripts/db-seed.sh reference   # roles, permissions, lookup values, system settings — safe for production
bash scripts/db-seed.sh demo        # ALSO loads DEMO_-prefixed sample records — dev/staging only, never production
```

Every migration in this repository has been applied end-to-end against a clean local PostgreSQL 16 instance as part of Phase 4 validation, including exercising Row Level Security as non-superuser sessions (see `docs/DATABASE.md` "Validation performed" section) — this is a tested schema, not an untested draft.

## Conventions

- No organization-specific rule (attendance threshold, probation length, ID formats, approval chain membership, categories) is ever hardcoded — all of it lives in `system_settings`, `lookup_values`, or `workflow_definitions` and is administrator-editable.
- Every table holding member-sensitive or confidential data has Row Level Security enabled with explicit policies — enforcement is at the database layer, not just the UI.
- No credentials of any kind are committed to this repository. Copy `.env.example` to `.env.local` and fill in real values locally / in your hosting provider's secret store.
